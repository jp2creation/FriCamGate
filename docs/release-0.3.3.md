# Camnory 0.3.3 TV preview

Follow-up to 0.3.2 after inspecting the physical Google TV launcher: its app
row applies a circular mask to the activity icon. A wide wordmark is cropped.
The TV activity now declares a separate square asset using the original
Camnory shield, with margin for the circular mask. Its rectangular banner
retains the complete supplied wordmark and slogan. Mobile icons are unchanged.

All 0.3.2 features are retained: four-camera TV pages, main-stream preference,
optional Frigate/HA local routes and removal of the redundant phone notification
refresh icon. See release-0.3.2.md for route contract and validation limits.
